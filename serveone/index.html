Main Project · SyncFlo

전자전표 솔루션 구축

기존 시스템을 분석하고
업무 흐름부터 다시 설계했습니다

전담 기획자가 없는 상황에서 기존 기능과 불편사항을 정리하고, 전표 작성·결재·조회·통계·관리자 기능의 흐름과 화면을 설계했습니다.

기간
2024.02 — 2025.01
역할
분석 · 화면 기획 · UI UX
범위
PC · Mobile · Design System

01 · 문제 정의

사용자의 불편을 파악하고
개선 과제를 정리했습니다

오래된 화면의 기능을 그대로 옮기지 않고, 회계 담당자와 일반 사용자의 불편을 역할과 업무 단계별로 정리했습니다.

회계 담당자반복 검토와 규정 변경 대응

수작업이 많아 처리 시간이 길어짐

일반 사용자복잡한 작성 화면과 높은 진입장벽

작성 항목이 많고 사용법이 어려움

02 · 프로세스 설계

권한과 상태를 기준으로
전표 처리 흐름을 정리했습니다

전표 작성·결재·조회·통계와 관리자 기능을 연결하고, 메뉴 구조부터 작성·상신·승인·확정까지의 흐름을 프로토타입으로 검증했습니다.

  1. 01요구사항 분석실무자·개발자 의견 확인
  2. 02IA와 권한접근·작성·조회 범위 정의
  3. 03전표 흐름작성·상신·승인·반려·확정
  4. 04프로토타입핵심 행동과 예외 상황 합의

03 · PC 핵심 UX

자주 하는 업무는 빠르게,
복잡한 상태는 명확하게

사용자는 입력과 상신에 집중하고, 관리자는 기준정보와 진행 상태를 유연하게 관리하도록 화면의 역할을 나눴습니다.

  1. 01개인화 대시보드와 퀵 메뉴탐색 동선 최소화
  2. 02작성·수정·상신 통합한 화면에서 업무 완료
  3. 03결재 상태와 비용 구분확인해야 할 정보를 먼저 표시
  4. 04반려 후 재기안반복 입력과 사용자 부담 감소

04 · 구현과 품질관리

디자인 전달에서 끝내지 않고
구현 결과까지 확인했습니다

PC 이후 모바일로 제품을 확장하고, 공통 컴포넌트와 QA 기준으로 화면 간 일관성과 예외 상황을 개발자와 조율했습니다.

  1. Mobile외근 중 경비 작성 · 증빙 첨부 · 승인
  2. Figma Component버튼 · 입력폼 · 상태값의 공통 기준
  3. Development Collaboration구현 차이와 예외 상황을 개발자와 조율
  4. 현재의 역할사내 솔루션 UI UX 검수 · 개선 방향 제안
